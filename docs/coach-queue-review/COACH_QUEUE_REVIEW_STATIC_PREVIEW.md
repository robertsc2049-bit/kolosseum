## 1. Purpose

The S54 Coach Queue / Review Static Preview Page creates a static HTML artifact for visual inspection of the coach queue review surface.

The preview uses S52 expected fixture responses and S53 renderer output only.

The preview exists so the coach queue review UI can be visually inspected and styled later against the Kolosseum brand feel.

## 3. Static preview artifact

This slice adds:

- `previews/coach-queue-review/static-preview.html`

The artifact is generated by:

- `scripts/render_coach_queue_review_static_preview.mjs`

The generator reads:

- `test/fixtures/coach-queue-review/expected_route_responses.json`

The generator imports:

- `dist/src/coachQueueReviewUiRenderer.js`

The generator must not import S51 route handler code.

## 4. Preview content

The preview must include:

- heading: `Coach Queue Review — Static Preview`
- visible non-production notice
- primary coach queue fixture render
- empty coach queue fixture render
- missing coach ID fixture render

## 5. Prohibited behaviour

The preview and generator must not:

- call fetch
- call XMLHttpRequest
- call axios
- import Express
- import database libraries
- register routes
- require auth
- mutate fixtures
- use current time
- use randomness
- create production navigation links
- create live API integration
- create advice, score, ranking, safety, medical, optimisation, or readiness-certification language
